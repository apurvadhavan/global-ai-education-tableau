Analytical Process

Project Methodology & Lifecycle

A transparent, 10-phase data analytics lifecycle spanning data extraction, data cleansing, exploratory data analysis, Tableau visualization, and Flask web deployment.

1
Data Collection & Extraction
Phase 1

Extracted the raw survey and administrative benchmark dataset data/raw/Global AI in Education.csv containing 1,360 monthly country-level records across 10 sovereign nations from January 2015 to April 2026.

Dimensions: 10 countries, 6 continental regions, 136 consecutive monthly observations.
2
Data Cleaning & Schema Audit
Phase 2

Conducted full structural verification across all 16 columns. Identified that standard pandas CSV parsers mistakenly interpret the literal category "None" in government_ai_policy as null/NaN. We explicitly prevented this silent mutation, maintaining the integrity of all 442 "None" records.

Missing Values: 0 | Duplicate Rows: 0 | Value Bounds: All percentages validated within [0, 100].
3
Data Preparation & Feature Engineering
Phase 3

Engineered derived metrics and chronological timestamps required for high-performance Tableau calculations and multi-scale temporal modeling.

Engineered Fields: date (ISO-8601 YYYY-MM-01), urban_rural_gap_pct (Urban - Rural), student_teacher_diff_pct (Student - Teacher), student_teacher_ratio.
4
Exploratory Data Analysis (EDA)
Phase 4

Implemented comprehensive 16-module exploratory analysis in analysis/data_analysis.ipynb analyzing descriptive statistics, correlations, temporal velocities, regional variances, and demographic gaps without fabricating assumptions.

Validated multi-year growth trajectory from 4.98% (2015) to 60.75% (2026).
5
Tableau Visualization Design
Phase 5

Designed 14 focused worksheets in Tableau addressing targeted analytical questions: choropleth adoption maps, dual-axis timelines, parity scatter plots, tool preference distributions, and policy boxplots.

Color-blind safe palettes, unified axes, and tooltip context formatting.
6
Executive Dashboard Assembly
Phase 6

Synthesized key worksheets into an interactive executive dashboard titled GLOBAL AI ADOPTION IN EDUCATION with 6 calculated KPI cards and global filters (Year, Month, Region, Country, Tool, Policy, Curriculum).

Filter actions set to apply across all worksheets using the data extract.
7
Tableau Story Construction
Phase 7

Constructed a 6-scene analytical narrative answering explicit questions from general global adoption to granular equity and accessibility dimensions, directly answering the 3 stakeholder personas.

Rigorous language standards: utilizing associational phrasing rather than unwarranted causal claims.
8
Performance Testing & Verification
Phase 8

Executed query and rendering audits. Pre-calculated date and gap fields in Python to eliminate real-time calculation overhead in Tableau. Documented manual verification guidelines for Tableau Performance Recording.

Documentation provided in documentation/performance_testing.md.
9
Tableau Public Publishing
Phase 9

Saved workbook as a packaged extract (tableau/Global_AI_Adoption.twbx) and published to Tableau Public with client-side rendering enabled, retrieving live share links.

Publicly hostable, zero database dependencies, high availability.
10
Flask Web Integration & Deployment
Phase 10

Built a modular Python Flask application with 6 dedicated routes, Tableau Embedding API v3 wrappers, live URL preview testers, and portfolio-ready documentation.

Runs locally via python app.py at http://127.0.0.1:5000/.

Methodological Summary & Academic Integrity

Every visualization, summary metric, and analytical narrative point in this project originates directly from the supplied Global AI in Education.csv dataset. All data transformations are fully transparent, documented in code, and reproducible via prepare_data.py.
